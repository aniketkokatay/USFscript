USFScript Language & MathOS

USFScript is a pure mathematical execution model designed to translate classical control flow constructs—conditionals, comparisons, loops, and state changes—into closed-form mathematical equations. Powered by the Universal Step Function (USF), USFScript eliminates programmatic branching in favor of continuous-to-discrete state transformations.

1. Mathematical Formulation

The core building block of USFScript is the 5-parameter Universal Step Function $o(x,y,z,p,q)$, constructed from elementary floor, ceiling, and absolute value operations:

$$o(x,y,z,p,q) = \left\lceil \frac{|g_x|}{|g_x| + 1} \right\rceil \cdot g_y$$

where $k_x = \lfloor x - z \rfloor$, $k_y = \lceil |y + q| \rceil$, $g_x = |k_x + 1| + k_x + 1 + p$, and $g_y = \left\lceil \frac{|k_y|}{|k_y| + 1} \right\rceil$.

Using $o(x,y,z,p,q)$, relational predicates and Boolean logic are derived deterministically without meta-notation:

  • Non-Strict Inequality ($x \ge y$): $g_1(x,y) = o(x, 1, y, 0, 0)$
  • Logical Equality ($x = y$): $e_f(x,y) = g_1(x,y) \cdot g_1(y,x)$
  • Primality Test Indicator ($p(j)$): For $k = \frac{(j-1)! + 1}{j}$, $$p(j) = o\left(\lfloor k \rfloor, 1, k, 0, 0\right) \cdot o\left(k, 1, \lfloor k \rfloor, 0, 0\right)$$

2. USFScript Python Implementation

Below is the Python evaluation engine demonstrating USF primitive evaluation and the algebraic computation of the $N^{\text{th}}$ Prime without programmatic conditional branching (if/else statements).

import math

def usf(x, y, z, p=0, q=0):
    """5-Parameter Universal Step Function Primitive."""
    kx = math.floor(x - z)
    ky = math.ceil(abs(y + q))
    gx = abs(kx + 1) + kx + 1 + p
    gy = math.ceil(abs(ky) / (abs(ky) + 1))
    return math.ceil(abs(gx) / (abs(gx) + 1)) * gy

def gte(x, y):
    """x >= y evaluated strictly via USF."""
    return usf(x, 1, y, 0, 0)

def equals(x, y):
    """Equality indicator e_f(x,y) evaluated strictly via USF."""
    return gte(x, y) * gte(y, x)

def is_prime(n):
    """Primality indicator evaluated algebraically."""
    divisor_count = sum(equals(n % d, 0) for d in range(1, n + 1))
    return equals(divisor_count, 2)

def nth_prime(n):
    """Calculates the N-th prime number via algebraic summation bounds."""
    limit = 2 if n == 1 else int(n * (math.log(n) + math.log(math.log(n)))) + 10
    result = 0
    for i in range(2, limit):
        primes_so_far = sum(is_prime(k) for k in range(2, i + 1))
        result += i * equals(primes_so_far, n) * is_prime(i)
    return result

# Verification
print("12th Prime Number:", nth_prime(12)) # Evaluates directly to 37

3. MathOS Screen & State Architecture

In MathOS, application state transitions are handled by binding each UI frame to an algebraic multiplier in USFScript that evaluates to $1$ when active and $0$ when inactive.

  • Screen 1 (Home Screen): Controls active workspace navigation registers.
  • Screen 2 (Pattern Analysis): Real-time numerical evaluator housing $N^{\text{th}}$ term engines for Prime, Fibonacci, Palindrome, and Armstrong sequences.
  • Screen 3 (Games Hub): Interactive switch register routing input events to mini-game states.
  • Screen 4 (Rock Paper Scissors): Algorithmic opponent engine evaluating move history frequency via algebraic counters.
  • Screen 5 (Guess the Number): Range-bound feedback engine rendering comparative vector indicators ($\uparrow, \downarrow$) based on parity state.
